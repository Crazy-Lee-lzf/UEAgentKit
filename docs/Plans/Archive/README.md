# UEAgentKit Plans Archive

This directory preserves completed and superseded development Plans/Results.

The files remain repository evidence and may be useful when implementing a related future capability, but they are **not current navigation entries**.

Start from:

```text
docs/Handoffs/UEAGENTKIT_CURRENT_DEVELOPMENT_HANDOFF_20260830.md
docs/DEVELOPMENT_WORKFLOW.md
docs/Plans/README.md
```

Then open only the archived Plan/Result relevant to the selected task.

Historical stage wording is intentionally preserved. Current Git facts and the current handoff override obsolete `next`, `blocked`, test-count, branch, or worktree wording in archived documents.
