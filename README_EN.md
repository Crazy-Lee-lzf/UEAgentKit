# UE Agent Kit

[中文](README.md)

> Turn Unreal Engine Blueprints into searchable, traceable project knowledge for developers and AI agents.

UE Agent Kit is an open-source Blueprint analysis toolkit for Unreal Engine. A UE Editor plugin extracts Blueprint data, while a Python CLI and SQLite index make assets, variables, functions, call relationships, and dependencies searchable across an entire project.

The current release is **0.2.4** and targets **Unreal Engine 5.6**. It is read-only and does not modify or save `.uasset` files.

> **AI Generated**: Most code and documentation in this project are generated by AI, then reviewed and validated through UE 5.6 builds, automated tests, and regression tests on real projects.

## What it can answer

Blueprints are stored as binary assets, so ordinary text search cannot answer many project-level questions. UE Agent Kit can help identify:

- Where a variable is read or written across Blueprints.
- Which assets call a function, interface message, macro, or event dispatcher.
- What a Blueprint inherits, which interfaces it implements, and which assets it depends on.
- Where Soft References, PrimaryAssetLabel management rules, and DataTable rows are referenced.
- How graphs, nodes, pins, and links are structured inside a large Blueprint.

Exports can be inspected directly or imported into SQLite for CLI, scripts, and future AI integrations without repeatedly loading complete Blueprints.

## Key capabilities

- Read Blueprint classes, parents, interfaces, variables, defaults, components, functions, and graphs.
- Export nodes, pins, links, and common node properties.
- Detect variable reads and writes, function and macro calls, interface messages, dynamic casts, delegates, inheritance, and interface implementations.
- Distinguish member variables, local variables, input, output, return, and reference parameters.
- Analyze hard and soft packages, Soft Object/Class references, Manage dependencies, and Searchable Names.
- Export Canonical JSON, BPCTX/1, and manifests.
- Build an incremental SQLite/FTS5 project index with forward and reverse reference queries.
- Support Unicode paths, localized content, and offline environments.

## Quick start

### Requirements

```text
Windows 10 / 11
Unreal Engine 5.6
Visual Studio C++ Toolchain
PowerShell 5.1+
Python 3.11 or 3.12
```

### 1. Build the plugin

```bat
scripts\BuildPluginDirect.cmd
```

The compiled plugin is written to:

```text
Build\Compiled\UEAgentKit
```

### 2. Export Blueprints

```bat
scripts\RunExport.cmd -Asset "/Game/Folder/BP_Name" -Profile logic -Format both
```

Export a directory:

```bat
scripts\RunExport.cmd -Root "/Game/Folder" -Profile ai -Format both -CompactJson
```

### 3. Build and query the index

```bat
scripts\ue-agent.cmd index build Output
scripts\ue-agent.cmd index stats
scripts\ue-agent.cmd search assets Door
scripts\ue-agent.cmd search symbols MaxWalkSpeed
scripts\ue-agent.cmd references --target-asset /Game/Characters/BP_Player
```

See [`docs/BUILD_AND_RUN.md`](docs/BUILD_AND_RUN.md) for project paths, Unreal Engine paths, plugin installation, and complete command options.

## Output

```text
Output\
├─ manifest.json
├─ canonical\
└─ bpctx\
```

- **Canonical JSON**: the complete and stable Blueprint fact model.
- **BPCTX/1**: a compact text format designed for selective AI context loading.
- **SQLite Index**: project-level search for assets, symbols, and references.
